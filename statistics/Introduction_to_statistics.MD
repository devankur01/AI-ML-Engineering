# Introduction to Statistics    

**What is Statistics?** 

Statistics is the science of collecting, organizing, analyzing, interpreting, and presenting data to make better decisions.     

In Simple words, Statistics is the process of turning raw data into useful information so that we can make better decisions.    

**Statistics helps us to understands the data.**

**Difference Between Them**     

| Descriptive Statistics       | Inferential Statistics |
| ---------------------------- | ---------------------- |
| Describes existing data      | Makes predictions      |
| Uses complete available data | Uses sample data       |
| Shows summaries              | Draws conclusions      |
| No prediction                | Prediction is possible |
